# Weekly Active User Growth Accounting Analysis

## 📊 Overview

This project analyzes **Weekly Active Users (WAU)** over 56 weeks using the **Growth Accounting framework** to understand the key drivers of user growth and churn.

The analysis was performed in **Microsoft Excel** using weekly user activity data.

## 🎯 Objectives

- Track Weekly Active User (WAU) growth
- Identify New, Retained, Resurrected, and Churned users
- Analyze Retention and Churn rates
- Calculate Quick Ratio and Net Growth
- Evaluate the sustainability of user growth
- Generate actionable business recommendations

## 🔍 Key Findings

- WAU increased from **1,759 to 3,696** — approximately **110% growth**
- Average retention rate: **72.29%**
- Average Quick Ratio: **1.06**
- New-user acquisition declined by approximately **12%**
- Resurrected users increased by approximately **43.79%**
- Churn increased by approximately **9.23%**
- Approximately **96% of positive user inflow was offset by churn**

## 💡 Business Recommendation

The analysis suggests focusing on **churn reduction, retention improvement, user reactivation, and stabilizing new-user acquisition** to build more sustainable growth.
